SOLAR CHARGE ADVISER — Android installable web app

1. Upload ALL files in this folder to an HTTPS static web host (for example GitHub Pages).
2. Open the resulting https:// URL in Chrome on Android.
3. Choose Chrome menu > Add to Home screen / Install app.
4. Enter current battery %, and adjust estimated daytime household usage.
5. Tap Refresh forecast to update tomorrow's recommendation.

This is a static app; opening index.html directly as a local file may show a forecast, but install/offline features require HTTPS hosting.
It does not connect to the inverter or Octopus account.
Default household daytime usage is a placeholder; calibrate this and the PV performance factor against actual readings.
Location uses approximate Heywood coordinates, not a street address.
